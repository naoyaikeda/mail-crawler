# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https.keepachangelog.com/en/1.0.0/),

## [1.0.0] - 2023-10-27

### Added

- Initial release of `mail-crawler`.
- Support for IMAP, Gmail (OAuth2), and Exchange (OAuth2) accounts.
- Command-line interface for adding, listing, clearing, and crawling accounts.
